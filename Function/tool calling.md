**Function calling** (вызов функций) — это возможность больших языковых моделей, автоматически определять, когда и какую внешнюю функцию или инструмент нужно вызвать для решения задачи пользователя. Модель получает описание доступных функций (их имена, параметры и назначение), анализирует запрос пользователя и при необходимости формирует вызов функции в виде структурированных данных (JSON с именем функции и аргументами). Затем этот вызов выполняется во внешнем коде или API, а результат возвращается модели для формирования окончательного ответа пользователю

В  пломпт модели передаются json список инструментов, которые модель может использовать, следующиего вида:
	-  ```"tools": [
	  {
		"type": "function",
		"function": {
		  "name": "set_spending_limit",
		  "description": "Установка лимита расходов для категории",
		  "parameters": {
			"type": "object",
			"properties": {
			  "categoryName": {
				"type": "string",
				"description": "Название категории расходов"
			  },
			  "amount": {
				"type": "number",
				"description": "Сумма лимита в рублях"
			  }
			},
			"required": ["categoryName", "amount"]
		  }
		}
	  },
	  {
		"type": "function",
		"function": {
		  "name": "execute_sql_query",
		  "description": "Выполнение SQL-запроса к базе транзакций",
		  "parameters": {
			"type": "object",
			"properties": {
			  "query": {
				"type": "string",
				"description": "SQL-запрос для выполнения"
			  }
			},
			"required": ["query"]
		  }
		}
	  }
	]```
Ответ модели может быть либо вызовом инструмента:
	`{`
	  `"tool_calls": [`
		`{`
		  `"id": "call_abc123",`
		  `"type": "function",`
		  `"function": {`
			`"name": "set_spending_limit",`
			`"arguments": "{\"categoryName\":\"Продукты\",\"amount\":15000}"`
		  `}`
		`}`
	  `]`
	`}`
либо генерацией текста:
	{
	"content": "Ваш лимит успешно установлен!"
	}
При вызове инструмента система отвечает  json сообщением, которое затем добавляется в историю чата, чтобы модель знала ответ инструмента
	{
	  "role": "tool",
	  "content": "результат_выполнения",
	  "tool_call_id": "идентификатор_вызова"
	}
