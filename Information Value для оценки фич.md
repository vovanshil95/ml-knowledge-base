**Information Value (IV) - Информационная ценность**

- **Что это?** Статистическая мера, оценивающая, **насколько хорошо признак (часто категорильный или дискретизированный непрерывный) разделяет "хорошие" и "плохие" события** (напр., дефолт/не дефолт). Тесно связана с **Weight of Evidence (WoE)**.
    
- **Как рассчитывается:**
    
    1. **Группировка:** Признак разбивается на интервалы/категории (`i`) если он не дискретный.
        
    2. **Расчет WoE для каждой группы:**  
        `WoE_i = ln( (Distr_Good_i / Distr_Good_total) / (Distr_Bad_i / Distr_Bad_total) ) = ln( %Good_i / %Bad_i )`
        
        - `Distr_Good_i`: Количество "хороших" в группе `i`
            
        - `Distr_Good_total`: Общее количество "хороших"
            
        - `Distr_Bad_i`: Количество "плохих" в группе `i`
            
        - `Distr_Bad_total`: Общее количество "плохих"
            
        - `%Good_i = Distr_Good_i / Distr_Good_total`
            
        - `%Bad_i = Distr_Bad_i / Distr_Bad_total`
            
        - **Интерпретация WoE:**
            
            - `WoE > 0`: Доля "хороших" в группе `i` **выше**, чем общая доля "хороших" (`%Good_i > %Bad_i`). Чем больше WoE, тем "лучше" группа.
                
            - `WoE < 0`: Доля "хороших" в группе `i` **ниже**, чем общая доля "хороших" (`%Good_i < %Bad_i`). Чем меньше WoE, тем "хуже" группа.
                
            - `WoE = 0`: Распределение "хороших" и "плохих" в группе соответствует общему распределению.
                
    3. **Расчет IV для каждой группы:**  
        `IV_i = (%Good_i - %Bad_i) * WoE_i`
        
    4. **Общий IV для признака:**  
        `IV_total = Σ (IV_i) for all groups i`
        
- **Интерпретация IV:**
    
    - **< 0.02:** **Практически бесполезен** (слишком слаб для предсказания)
        
    - **0.02 - 0.1:** **Слабый** предиктор
        
    - **0.1 - 0.3:** **Средний** предиктор
        
    - **> 0.3:** **Сильный** предиктор
        
    - **> 0.5 и выше:** **Слишком сильный?** Требует перепроверки. Возможны утечки данных, overfitting или ошибки в расчете. Может указывать на дублирующий признак.
        
- **Применение в Feature Engineering:**
    
    - **Отбор признаков:** Фильтрация слабых признаков (IV < 0.02 или < 0.1).
        
    - **Кодирование категориальных переменных:** Категории признака заменяются на их WoE. Это преобразует категориальный признак в мощный числовой, отражающий его связь с целью и делающий данные более линейно разделимыми для моделей (особенно для логистической регрессии).
        
    - **Биннинг (дискретизация) непрерывных признаков:** Поиск оптимальных интервалов для разбиения непрерывного признака, максимизирующих IV.
        
    - **Контроль мультиколлинеарности:** Признаки с очень высоким IV (>0.5) могут быть сильно коррелированы друг с другом или с целью. Требуют анализа.
        
- **Преимущества:**
    
    - Прямо измеряет способность разделять классы.
        
    - Имеет четкую интерпретацию и пороговые значения.
        
    - Основа для мощного кодирования WoE.
        
    - Устойчив к нелинейным зависимостям (при правильном биннинге).
        
- **Недостатки / Осторожность:**
    
    - **Требует бинарной цели.**
        
    - Чувствителен к способу биннинга. Плохой биннинг исказит IV.
        
    - Чувствителен к малым группам (может давать завышенный IV). Применяют правила (напр., min 5% наблюдений в бине, объединение мелких групп).
        
    - WoE/IV могут "протекать" информацию о целевой переменной в данные (особенно при кодировании всей выборки без разделения на train/test). **Кодировать WoE нужно ТОЛЬКО на основе статистик тренировочного набора!**
        
    - Не показывает направление влияния (это делает WoE).
