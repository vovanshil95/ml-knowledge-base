На этой странице представлен практический pipeline для RAG-системы, реализующий один из самых эффективных и современных подходов к поиску текста и изображений.

-  **Этап 1: Индексация данных (Offline)**
	- Сбор отчиста источников текста и картинок (PDF, базы знаний, веб-страницы, SQL)
	- Чанкинг (разбиение на фрагменты длиной 512-1024 токена с перекрытием)
	- Векторизация каждого чанка Bert подобной эмбединг моделью (например`BAAI/bge-large-en-v1.5` или `voyage-lite-01`) 
	- Индексация векторов `HNSW в FAISS`
	- Индексация на основе ключевых слов `BM25 (ElasticSearch)` или `SPLADE`
	- Индексация на основе изображений через `CLIP`
-  **Этап 2: Retrieval (Поиск кандидатов)**
	- Получение запроса пользователя, генерация более лёгкой LLM нескольких синонимичных запросов/вариантов запроса/уточняищих запросов 
	- **Векторный поиск** (семантическое сходство) по индексу `HNSW в FAISS` для каждого запроса паралельно.
	- **Sparse-поиск** по индексу `BM25 (ElasticSearch)` для каждого запроса паралельно
	- Объединение например топ 30 по векторному поиску и топ 20 по sparse поиску, итого 50 чанков на каждый запрос.
	- Дедупликация одинаковых чанков (полученных из разных запросов)
	- Реранкинг на основе Bert-like классификатора (reranker) который берёт последовательность `[CLS] Запрос [SEP] Документ [SEP]` и возвращаетс скаляр - релевантность документа (чанка) при ответе на запрос
	- Выбор топ-5-10 кандидатов на основе реранкинга
- **Этап 3: Генерация**
	- добавление текста чанков в PROMPT
	- Добавление ссылок на источники (на документы из чанков)
