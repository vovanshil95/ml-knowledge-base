ReAct framework — это метод, который позволяет моделям эффективно сочетать две ключевые способности: Reasoning (рассуждение) и Acting (действие) в одном цикле. Это выражается в том, что модель чередует генерацию промежуточных рассуждений («мысли») и выполнение конкретных действий (например, вызов API, поиск информации, выполнение команд), после чего использует полученные результаты для обновления своих мыслей и принятия дальнейших решений

Алгоритм работы LLM заключается в следующем

1. модель получает запрос пользователя
2. модель рассуждает и решает может ли она отвеить на вопрос
	- если может, то отвечает
	- если не может то идёт к 3 пункту
3. модель получает список инструментов и использует подходящий если он есть
4. модель получает результат выполнения инструментов и возвращается к пункту 2
