**Задача object detection (обнаружение объектов)** в компьютерном зрении заключается в том, чтобы найти на изображении все объекты заданных классов и локализовать их с помощью ограничивающих прямоугольников (bounding boxes), то есть определить и класс объекта, и его координаты на картинке

Основные этапы:

- Классификация объекта (что это за объект)
    
- Локализация объекта (где он находится, обычно задаётся рамкой с координатами)

Для задачи могут быть применены архитектуры [[R-CNN]] или [[YOLO]]
