**Оффлайн**
	**Для обычного поиска**:
	- `Recall = (Количество релевантных извлеченных) / (Всего релевантных в коллекции)`
	- `Precision = (Количество релевантных извлеченных) / (Всего извлеченных)`
	- `F1 = 2 * (Precision * Recall) / (Precision + Recall)`
	- `Precision@k (P@k)` - Precision на первых топ k элементах ранжирования
	- `Recall@k (R@k)` - Recall на первых топ k элементах ранжирования
	- `F1-Score@k` - тут понятно 
	- `Average Precision (AP)` - среднее из нескольких `Precision@k` где k все  позиции релевантных элементов в списке выдачи
	- `DCG = rel₁ + Σᵢ (relᵢ / log₂(i+1))`
	- `nDCG = DCG / IDCG`
	- **Reciprocal Rank** ` RR = 1 / rank`, где `rank` это номер самого первого релевантного элемента в выдаче
	**Для [[RAG (Retrieval-Augmented Generation) идея|RAG]]**:
	- **Reciprocal Rank** (из обычного поиска)
	- **Hit Rate@k** - доля запросов в которых найдётся хотя-бы один релевантеый чанк
	- **nDCG** (из обычного поиска)
	Все эти метрики, кроме **Reciprocal Rank** рассчитываются для одного запроса и их можн усреднять для всех запросов, чтобы иметь понимание о качестве алгоритма
**Онлайн**
	- Оценка поиска/ответа от людей/LLM 1-5
	- CTR
	- Latency
	- RAGAS фреймворк
		1.**Faithfulness (Фактическая точность)**
			1. LLM судья берёт ответ rag системы и извлекает все утверждения из него
			2. для каждого утверждения проверяет было ли оно в предоставленном контексте
			3. возвращает `количество утверждений из ответа найденных в контексте / количество утверждений из ответа`
		2.**Answer Relevance (Релевантность ответа)**
			- LLM судья генерирует все гипотетические вопросы на которые мог бы отвечать ответ RAG системы
			- считаем среднюю косинусную близовсть вопросов и оригинального вопроса на который отвечала RAG система
		3.**Context Precision**
			- Для каждой части контекста/чанка модель оценивает релевантен ли он для вопроса или нет
			- считаем `релевантные части контекста / все части контекста`
		**4. Context Recall (Полнота контекста)**
			- LLM судья берёт все аспекты вопроса
			- Считает `количество упомянутых в контексте аспектов вопроса / количекство аспектов вопроса`
