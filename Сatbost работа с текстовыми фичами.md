Для преобразования текстовых признаков Catboost сначала проводит токенизацию
По умолчанию он делает токенизацию разделяя слова пробелами, а затем строя биграммы и униграммы, с ограничением размера словаря на 50 000 для униграмм и 50 000 на для биграмм

Далее когда есть набор токенов можно их векторизовать, по умолчанию это делается двумя способами 
- [[Как можно численно представить текстовые данные?|Bag of words]], с получением sparse матрицы фичей размером len(X) на vocab_size
- NaiveBayes - рассчитываетсся как `P(word | class_k) = (count(word in class_k) + α) / (total_words_in_class_k + α * vocab_size)` далее `feature = Σ [ log(P(token | class_k)) ] по всем токенам текста`, таким образом добавляется по одной фиче на каждый класс

после bag of words  энкодинга количество фичей в датасете растёт до 100 000 если словарь достиг максимума, но Catboost оптимизирован для работы с такими sparse матрицами
