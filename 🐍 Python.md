- отличие __ new __ от __ init __
        
        **Различия между `__new__` и `__init__`**
        
        - **Тип метода**: `__new__` является статическим методом, в то время как `__init__` является методом экземпляра.
        - **Ответственность**: `__new__` отвечает за создание и возврат нового экземпляра класса, в то время как `__init__` отвечает за инициализацию атрибутов только что созданного объекта.
        - **Порядок вызова**: `__new__` вызывается до `__init__`. Процесс начинается с вызова `__new__`, затем следует вызов `__init__`.
        - **Возвращаемое значение**: `__new__` может возвращать любой объект, в то время как `__init__` всегда должен возвращать `None`.
        
        **Пример использования**
        
        `class Person: def **new**(cls, name, age): print("Creating a new Person object") instance = super().**new**(cls) return instance
        
        ```
          def __init__(self, name, age):
              print("Initializing the Person object")
              self.name = name
              self.age = age
        ```
        
        person = Person("John Doe", 30) print(f"Person's name: {[person.name](http://person.name)}, age: {person.age}")`
